# 固定支出追蹤簿

追蹤每月固定支出（貸款、軟體訂閱、AI 服務、影音串流、電信、保險……），
把不同扣款週期換算成「每月等值」，一眼看出每月／每年到底被綁走多少錢。

單一檔案、零安裝、零後端：`index.html` 打開就能用。

## 怎麼用

| 方式 | 做法 |
|---|---|
| 網站 | https://josper1221.github.io/fixed-cost-tracker/ |
| 本機 | 直接用瀏覽器打開 `index.html`（雙擊即可） |
| Claude Artifact | https://claude.ai/code/artifact/b6606486-eaad-4511-bab4-8d5e6c88ac65 |

## 功能

**支出項目** — 名稱、分類、金額、幣別、扣款週期、下次扣款日、結束日、付款方式、狀態、備註。
可新增／編輯／複製／暫停／刪除。按 `N` 快速新增。

**週期** — 每週、每兩週、每月、每兩月、每季、每半年、每年，或自訂「每 N 個月」。
全部自動換算成每月等值與每年等值。

**分類** — 預設八類（貸款／軟體訂閱／AI 服務／影音串流／雲端儲存／電信網路／保險／其他），
可自由改名、增刪、換顏色。顏色組合已通過色盲與對比檢核。

**貸款** — 填上結束日期就會自動算出剩餘期數與剩餘總額。

**多幣別** — 訂閱用 USD、房貸用 TWD 都沒問題。匯率是自己填的固定值（不連網），
主要幣別可隨時切換，切換時匯率自動換算。

**側邊欄** — 總覽／全部項目／各分類／已暫停。分類清單是依你自己的分類自動長出來的，
每一項旁邊直接顯示該分類的每月金額。點任一個分類，底下所有數字、圖表、明細都只算那一類。
手機上收成漢堡選單的抽屜。

**Dashboard**
- 每月／每年固定支出總額，以及換算成每天多少錢
- 各分類每月開銷排行（點一下就跳到該分類）
- 未來 12 個月的實際扣款分佈 — 年繳、季繳集中在哪個月一目了然
- 接下來 7 天要扣的款，今天／明天／後天會標成琥珀色

以上四項在單一分類檢視下會自動換算成只屬於那個分類的數字。

**明細表** — 搜尋、依分類／狀態篩選、依金額／扣款日／名稱／分類排序。

**資料** — 匯出 JSON 備份、匯出 CSV（Excel 可開）、匯入 JSON、一鍵清除。

**使用者檔案** — 同一台裝置上可建立多組獨立帳本（例如「我的／家用／公司」），
或讓不同人各記各的。

**外觀** — 深色／淺色／跟隨系統。

## 資料存在哪裡

存在**你這台裝置的瀏覽器 localStorage** 裡（key: `fixedcost.ledger.v1`），
不會上傳到任何伺服器。這代表：

- 每個打開這個網頁的人，看到的都是自己的資料，互不干擾 — 這就是「大家都能用」的實作方式
- 換電腦、換瀏覽器不會同步；清除瀏覽器資料會一併清掉
- **換裝置前請先用「資料 → 匯出 JSON 備份」，到新裝置再匯入**

要做到跨裝置同步或多人共編，需要加後端（帳號登入 + 資料庫），那是另一個工程。
